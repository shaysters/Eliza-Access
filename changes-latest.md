# Eliza Access 1.0.1

Run **ElizaAccessInstaller.exe** (or the one you already have) to install or update. Close the game first. The full guide, with every key, is in the README on the GitHub page, and also comes in the download as ElizaAccess-README.html and ElizaAccess-README.md.

## Changes since 1.0.0

- Pressing Up or Down past the first or last option in a choice now reads the option again, instead of going silent. A single choice is read again on each press.
- Moving the mouse or touchpad no longer clears the selected choice or swallows an arrow press, so the next Down no longer jumps back to the first option.
- In counselling sessions, the number of choices is always announced before the option, including after returning from the pause menu.
